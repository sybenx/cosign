Cosign 0.11.2 (beta)

- Public servers no longer connect where a stranger points them: relays must be public wss:// addresses (checked at every connect), push goes only to allowed https:// hosts, and each server caps what one stranger can use (COSIGN_MAX_GROUPS, COSIGN_ENROLL_PER_HOUR, COSIGN_GROUP_PER_MINUTE, COSIGN_MAX_RELAYS).
- A fresh server's own key is now made by your phone and that server together, so no box holds enough to sign alone. The old throwaway 2-of-3 is only COSIGN_PERSONAL=dealt.
- Add a server (Home): add another public server to a key you already have.
- Paper backup: print or save the QR (as a PDF), or copy it to a password manager; paste a backup code to restore.
- Fixed: a paper restore could fail after a refresh that never finished; a device could stop signing after a late member list from before a refresh.
- A second public server: cosign-cf.aaro.cc (a Cloudflare Worker).
